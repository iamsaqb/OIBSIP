## 📊 Completed Internship Projects

### Task 1: Exploratory Data Analysis on Retail Sales

**Status:** Completed

**Objective:** Analyze retail sales data to identify meaningful business insights, trends, and patterns.

**Key Highlights:**
- Explored retail sales data using Python.
- Identified monthly sales patterns.
- Analyzed sales across different product categories.
- Examined profitability across product sub-categories.
- Investigated relationships between sales, quantity, discount, and profit.
- Created visualizations to communicate analytical findings.

**Technologies Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

🔗 **Project:** [View Task 1 on GitHub](./Saquib_Akhter_Task01/)

---

### Task 2: Customer Segmentation Analysis

**Status:** Completed

**Objective:** Analyze customer purchasing behavior and identify customer segments using data analysis and clustering techniques.

**Key Highlights:**
- Explored and analyzed the Online Retail dataset.
- Performed data preprocessing and preparation.
- Analyzed customer purchasing behavior.
- Applied clustering techniques to identify customer groups.
- Studied customer segment characteristics.
- Created visualizations to understand customer segments.

**Technologies Used:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

🔗 **Project:** [View Task 2 on GitHub](./Saquib_Akhter_Task02/)

---

### Task 3: Data Cleaning and Preprocessing

**Status:** Completed

**Objective:** Improve the quality and consistency of a Retail Store Sales dataset through systematic data cleaning and preprocessing.

**Key Highlights:**
- Identified and investigated missing values.
- Applied appropriate missing value handling strategies.
- Checked duplicate records.
- Standardized text and categorical values.
- Corrected data types.
- Detected and investigated potential outliers using the IQR method.
- Generated before-and-after data quality reports.
- Exported the cleaned dataset for further analysis.

**Technologies Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

🔗 **Project:** [View Task 3 on GitHub](./Saquib_Akhter_Task03/)
