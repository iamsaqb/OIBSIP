# Task 2: Customer Segmentation

**Oasis Infobyte Internship — Data Analytics**

## Project Overview

This project analyzes online retail transaction data to identify customer segments and understand purchasing behavior. Python is used for data analysis, customer segmentation, and generating summary reports.

## Objectives

- Explore and prepare online retail transaction data.
- Analyze customer purchasing patterns.
- Group customers into meaningful segments.
- Summarize customer segments and revenue.
- Generate CSV outputs to support further analysis.

## Technologies Used

- Python
- Jupyter Notebook
- Pandas and NumPy
- Data visualization libraries used in the notebook
- Excel and CSV datasets

Dataset
The project uses the Online Retail.xlsx transaction dataset.

The notebook should be run from the project directory so that relative file paths can resolve correctly.
Outputs
- cluster_profile.csv — Summary information for the generated customer clusters.
- customer_segments.csv — Customer-level segment assignments.
- revenue_summary.csv — Revenue summary generated by the analysis.
- screenshots/ — Visual evidence of the project and its results.
How to Run
1. Install Python and Jupyter Notebook.
2. Open a terminal in the project directory.
3. Create and activate a virtual environment if needed.
4. Install the required packages:
   pip install -r requirements.txt
5. Open the notebook:
   jupyter notebook customer_segmentation.ipynb
6. Run the notebook cells in order.
Conclusion
This project demonstrates how Python-based exploratory analysis and customer segmentation can help organize retail customers into groups and summarize their purchasing behavior. The generated reports can support further business analysis and decision-making.
